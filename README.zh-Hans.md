# EdgeTodo ✿

[English](README.md) | [繁體中文](README.zh-Hant.md) | **简体中文**

**一个住在 Mac 屏幕边缘的待办清单，让你再也不会忘记查看。**

大部分待办应用都要你停下手头的工作，再打开另一个应用。EdgeTodo 平时只会在屏幕右边露出一条细边：鼠标移过去，它就会滑出来；鼠标移开，它又会自动收回去。

## 功能

- 🫧 **划过即看**：平时收在屏幕边缘，鼠标移过去就会弹出
- 📌 **固定常驻**：固定后面板会变成液态玻璃（Liquid Glass，需要 macOS 26 或以上）
  - 正在使用时：液态玻璃加磨砂，方便阅读
  - 使用其他应用时：完全透明的玻璃，可以看到下面的内容
- 🔁 **重复任务**
  - *随时重复*：适合经常做但不一定每天做的事，例如健身、洗衣服。每点一下就记录一次完成时间，并显示“last: 3 days ago · 12×”
  - *定期*：每天、每周、每月，或任何自定义间隔（每 3 天、每 2 周……）。完成后会显示下次到期日，到期会自动重新出现，逾期会变红提醒。每日任务还会显示 🔥 连续完成天数
- ⏰ **截止日期与提醒**：可以为任何任务设置截止日期。快到期时，任务会自动移到最上方的“due soon”区域，颜色会由黄 → 橙 → 红。有任务今天到期或已逾期时，屏幕边缘会发光（面板收起来也看得到），菜单栏图标会显示数量，并会在到期前一天和当天发送通知
- 📌 **任务置顶**：重要的任务会固定在最上方的高亮区域
- ↕️ **拖拽排序**：随意调整任务顺序，甚至可以拖到其他分类
- 🗂 **分类与状态**：用 `#work`、`#life`、`#study` 等标签分类，并可分到 To-do / Pending / Done / Cancelled
- 🎨 **全面自定义**：字体（可使用 Mac 上的任何字体）、粗细、大小、文字颜色、强调色、背景色调、透明度、尺寸、圆角
- 🤖 **AI 友好**：任务保存在一个纯 JSON 文件里，任何 AI 助手或脚本都可以帮你添加任务，面板会在一秒内更新
- 🪶 **轻巧原生**：只有一个 Swift 文件，不需要任何依赖、账号或云服务

## 安装

需要 macOS 12 或以上（液态玻璃需要 macOS 26 或以上）。

1. 下载这个仓库（**Code → Download ZIP**），然后解压
2. 打开“**终端**”，输入 `bash `（后面有一个空格），把 `build.sh` 拖进窗口，再按回车
3. 如果 macOS 提示安装 **Command Line Tools**，安装完成后再执行一次第 2 步

脚本会自动编译应用、安装到 `/Applications`，然后启动它。

## 使用方法

| 操作 | 方法 |
|---|---|
| 打开面板 | 把鼠标移到屏幕最右边（上半部分） |
| 添加任务 | 在底部输入。加上 `#分类` 即可归类，例如 `剪辑素材 #content` |
| 完成任务 | 点击方框 |
| 添加重复任务 | 点击 + 旁边的 ↻ 按钮（依次切换：不重复 → 随时重复 → 每天 → 每周 → 每月），或直接输入：`/repeat`、`/daily`、`/weekly`、`/monthly`，或自定义间隔如 `/3d`（3 天）、`/2w`（2 周）、`/6m`（6 个月）、`/every 10 days`，例如 `浇花 #home /3d` |
| 设置截止日期 | 点击 + 旁边的 📅 按钮选择日期（可加时间），或直接输入：`/due fri`、`/due 10/25`、`/due 10/25 6pm`、`/due 3d`、`/today`、`/tmr 9am`，例如 `论文 #study /due fri 11:59pm` |
| 修改或移除截止日期 | 右键 → **Due Date** |
| 记录重复任务 | 点击任务的 ↻ 图标，每点一次就记录一次完成时间 |
| 调整顺序 | 把任务拖到新位置。拖到其他分类会一并修改分类，拖进 📌 区域会自动置顶。也可以右键 → **Move Up / Move Down** |
| 任务置顶 | 右键 → **Pin to Top** |
| 把现有任务改为重复 | 右键 → **Repeat**（选择预设，或选 **Custom interval…** 自定义每 N 天／周／月） |
| 撤销打卡 | 右键 → **Undo Last Check-in** |
| 移动、改分类、删除 | 在任务上点右键 |
| 保持面板打开 | 点击 📌 |
| 提醒设置 | Settings → **Due Dates & Reminders**：“快到期”的天数、提醒时间、屏幕边缘发光、通知 |
| 设置 | 点击面板上的 ⚙︎，或菜单栏的 ☑︎ 图标 → **Settings…**（⌘,） |
| 开机自动启动 | 菜单栏的 ☑︎ 图标 → **Open at Login** |

## 让 AI 帮你添加任务

所有任务都保存在 `~/EdgeTodo/todos.json`。让你的 AI 助手访问 `~/EdgeTodo` 文件夹，然后说“把‘订周五晚饭’加到我的待办清单”，面板就会在一秒内更新。

只有 `title` 是必填项，其他字段都有默认值：

```json
{
  "todos": [
    { "title": "weekly report", "category": "work", "status": "todo" }
  ]
}
```

`status` 可以是 `todo`、`pending`、`completed` 或 `cancelled`。

加上 `"due": "2026-10-25"`（或连时间 `"2026-10-25 18:00"`）可以设置截止日期。加上 `"pinned": true` 可以让任务置顶。重复任务加上 `"repeat": "anytime"`，或定期设置如 `"repeat": "every", "every": 3, "unit": "day"`（`unit` 可以是 `day`、`week` 或 `month`；也可以直接写 `"daily"`、`"weekly"`、`"monthly"`）。应用会记录 `lastDone` 和每次打卡时间的 `history`（ISO 8601 格式），方便你让 AI 帮你分析习惯。

## 手动编译

```bash
swiftc -O -parse-as-library EdgeTodo.swift -o EdgeTodo
```

使用 macOS 26 或以上的 SDK 编译时，加上 `-D GLASS` 即可启用液态玻璃。`build.sh` 会自动处理这一步，也会自动解决 SDK 与编译器版本不匹配的问题。
